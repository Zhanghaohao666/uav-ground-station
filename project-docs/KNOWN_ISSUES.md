# 已知限制和未完成项

这些记录来自原始版代码审查及后续修改范围，不表示每个问题都已做完整硬件复测。后续视频改动没有自动修复下面的控制问题。

- 可操作画面共用控制 TCP 对象，没有逐相机绑定控制目标；切换视频方案不会切换控制连接。云台用主控 9000，算法板用 9001。仅应在与算法输入相符的画面发送跟踪操作。
- 云台方向按钮缺少取消、隐藏、失焦时的统一停止处理；硬件是否有超时保护需现场验证。
- 控制 TCP 意外断开不会自动重连，需要手动连接；视频重连不等于控制已恢复。
- 脚本反馈没有完整隔离 task_id；旧任务反馈可能覆盖新任务展示。断线重连还可能保留半包。
- 部分连接/检测状态由本地乐观更新，不能直接作为设备已经执行成功的证明。
- 录像主要覆盖前两路，截图主要覆盖第一路；按需停流会终止对应接收器的录像，不自动续录。
- 部分视频总状态由多个接收器共享，不能全部代表某个具体窗口。
- 集群/RViz 等部分页面仍是占位；激光测距完整地面站业务链路未在这些版本中实现。
- 红外预览不等于红外检测、跟踪或测温。新版明确禁用的红外窗口不发送画面跟踪命令。
- 当前只完成源码与隔离回归；Windows UI、真实 GStreamer 解码、远距离 MK22 及飞行联调仍需验收。
