# 离线机器码 / 粘贴激活码

v1.01.13-activation-code-rc1 使用纯文字激活：客户发送机器码，管理员回复激活码。
双方不需要交换申请文件或授权文件，也不需要互联网。授权完成后自动保存，下次直接进入地面站。

## 客户怎么操作

1. 完整解压运行包，关闭旧程序，双击 `NexusGround.exe`。
2. 首次运行点击“复制机器码”，把完整的 `NGL1-...` 文字发给管理员。
3. 收到管理员发来的 `NGAC1.` 开头的激活码，完整粘贴到“激活码”框，点击“激活”。支持复制时附带的空格和换行。
4. 验证通过后自动进入地面站，以后正常打开不再弹激活窗口；软件自动保存，无需手动保存任何文件。

同一台电脑的机器码保持稳定，不随每次启动、软件版本、软件目录或网卡变化。
一个激活码绑定一台电脑；复制给另一台电脑不能激活。支持永久或限期授权。
运行 `License-Information.cmd` 或 `NexusGround.exe --license` 可主动查看授权信息或粘贴续期激活码。

授权与视频设置和运行目录分别保存；更新运行包、切换方案和清理软件设置不会主动删除授权。
同一台电脑换 Windows 用户账号时，在新账号下粘贴同一个激活码即可。
重装 Windows、换主板或系统固件身份变化可能改变机器码，需要重新签发。
限期授权按中国时区日期含当天计算；到期在下次启动时检查，已运行会话不会被突然中断。
系统时间明显早于签发时间时会拒绝激活，请校准时间。

## 管理员怎么操作

使用新版独立 `NexusLicenseAuthority.exe`，不用安装 Python/Qt。不要把管理员工具和私钥发给客户。

1. 双击管理员工具。同目录的 `owner-key.private.pem` 自动加载，不需要重新创建密钥。
2. 粘贴客户机器码，填写授权对象；到期日期不填为永久，或填 `YYYY-MM-DD`。
3. 点击“生成激活码”，再点击“复制激活码”，把文字发给客户。

输入内容变化后会清空之前生成的激活码，避免把上一位客户的码误发出去。
签发失败不会留下可复制的旧结果。激活码包含完整签名，比普通密码长，请整段复制。
仅管理员的密钥配置涉及私钥文件；客户激活流程没有文件操作。

命令行也可直接生成文字：

```bash
python3 -m pip install -r tools/licensing/requirements.txt
python3 tools/licensing/license_authority.py issue \
  --private-key /安全目录/owner-key.private.pem \
  --machine 'NGL1-完整机器码' \
  --customer '授权对象' --code
```

到期时间可加 `--expires 2030-01-01`；加密私钥可加 `--ask-password`。
旧命令的 `--request` 和 `--out` 仅为旧客户端维护保留，新界面没有导出申请和导入授权按钮。
已有 `.nglic` 可以由管理员调用 `activation_code(envelope)` 转成激活码，原签名和有效期不变。
**密钥及机器码算法不变，已激活电脑的现有授权继续生效，不需要重新激活。**

## 实现与验证

- 文本格式为 `NGAC1.<密钥编号>.<Base64URL负载>.<Base64URL签名>`，不加 Base64 填充，不压缩。
- RSA-3072 / PSS / SHA-256，salt 32 字节；Windows 系统 CNG、Linux OpenSSL 验签。只信任内置公钥。
- 解析只移除 ASCII 空格、制表符、CR/LF；拒绝隐藏字符、非法/非规范 Base64、错误长度和超过 16384 字符的输入。
- 文本还原精确的签名原文，再验证签名、本机、产品、功能和日期；不提供通用激活码或运行时绕过入口。
- 验证通过后原子保存；错误码、过期码、其他电脑的码均不覆盖已有有效授权。旧授权保存格式保持兼容。
- 授权仅在启动时检查，不对视频逐帧验签，不增加联网心跳。
- 中文使用明确 UTF-8 字节显式解码，保留 rc4 对 Qt 5/MSVC 字符集问题的修复。
- 自动测试覆盖签名、策略、文字编码、换行粘贴、篡改、重新读取、写入失败保护、真实 Qt 窗口粘贴和管理员 GUI 的生成/复制/过期结果清除。
- Windows CI 分别测试 UTF-8/CP1252 编码，检查正式 EXE 的实际中文文本和窗口截图，同时保留 TCP/UDP 解码及环境隔离检查。
- CI 不持有生产私钥。生产 EXE 授权后的视频、控制及室外效果需在真实授权电脑验收，窗口检查不替代视频验收。

私钥在本地隔离保存，不能上传 GitHub 或放入客户运行包，禁止重新初始化或随意更换生产密钥。
定期单独安全备份；私钥丢失后无法继续签发匹配当前程序的授权，泄漏则可能被他人签发授权。
客户 ZIP 不包含私钥、客户激活码和管理员工具。

离线授权无法即时远程撤销，不能绝对防本地时钟回拨或破解。公开旧运行包不会自动失效；公开源码可被修改重编译。
授权不限制其他播放器访问板端 RTSP/TCP。项目及依赖的开源许可继续保留，新增激活不改变这些许可。
